# 明星志愿 1 · 养成资料站

面向《明星志愿 1》DOS 原版怀旧玩家的资料库与养成辅助工具。站点采用纯静态 HTML、CSS 和 JavaScript 构建，可直接部署到 GitHub Pages。

## 功能

- 奖项资料库：查看赛事日期、入围方向、判定规则与资料来源
- 打工资料库：查询 12 项打工的精确门槛、属性变化与收入，并查看公司形象、公关、随机 NPC 和项目开放检查点
- 训练资料库：查询 10 项实际可用课程的四级属性与压力精确值
- 养成规划：按当前可用活动和训练等级生成“最快达标”估算周计划
- 响应式布局：支持桌面和手机浏览

## 数据说明

当前版本为 `2026.08-M5`。12 项打工和 10 项训练的用户精确数值表已录入；打工页补充了公司形象、公关增长方式、眼镜男刷法及玩家流程检查点，并区分确认规则与社区经验。“最快达标”按每次活动 1 天、每周最多 7 次生成估算方案。训练费用、成长上限、随机波动和失败分支尚未纳入。

## 本地运行

这是一个无构建步骤的静态站点。可直接打开 `index.html`，也可以在目录中启动任意静态文件服务器。

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 目录

```text
assets/      图片与本地第三方资源
app.js       页面交互与规划逻辑
data.js      攻略资料数据
index.html   页面结构
styles.css   页面样式
```

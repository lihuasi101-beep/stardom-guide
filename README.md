# 明星志愿 1 · 养成资料站

面向《明星志愿 1》DOS 原版怀旧玩家的资料库与养成辅助工具。站点采用纯静态 HTML、CSS 和 JavaScript 构建，可直接部署到 GitHub Pages。

## 功能

- 奖项资料库：查看赛事日期、入围方向、判定规则与资料来源
- 属性查询：选择一个属性，同时比较相关打工与训练的收益、副作用、压力和条件
- 打工资料库：查询 12 项打工的精确门槛、属性变化与收入，并查看公司形象、公关、随机 NPC 和项目开放检查点
- 训练资料库：查询 10 项实际可用课程的四级属性与压力精确值
- 养成规划：按当前可用活动和训练等级生成“最快达标”估算周计划
- 档期计算：分别保存最多 3 位艺人的已有与待接通告，逐日检查冲突，提供全员并行日历与表单错误自动定位
- 响应式布局：支持桌面和手机浏览

## 数据说明

当前版本为 `2026.08-M11`。资料库可在同一张表中比较 12 项打工和 10 项训练；“最快达标”按每次活动 1 天、每周最多 7 次生成估算方案。档期计算器支持 3 位艺人资料快速切换和并行总览；每位艺人采用单日一个工作槽、截止日最早优先的逐日匹配，不同艺人的工作槽相互独立。表单校验会定位对应艺人、通告和输入控件，并在修正后实时清除错误。签约限制仍保留为游戏内确认项，训练费用、成长上限、随机波动和失败分支尚未纳入。

## 本地运行

这是一个无构建步骤的静态站点。可直接打开 `index.html`，也可以在目录中启动任意静态文件服务器。

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 目录

```text
assets/      图片与本地第三方资源
app.js       页面交互与规划逻辑
data.js      攻略资料数据
index.html   页面结构
styles.css   页面样式
```

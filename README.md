# 明星志愿 1 · 养成资料站

面向《明星志愿 1》DOS 原版怀旧玩家的资料库与养成辅助工具。站点采用纯静态 HTML、CSS 和 JavaScript 构建，可直接部署到 GitHub Pages。

## 功能

- 奖项资料库：查看赛事日期、入围方向、判定规则与资料来源
- 打工资料库：查询 12 项打工的精确门槛、属性增减、压力、名气、能力加权和收入
- 训练资料库：查询 10 项课程的四级属性与压力精确值，并保留分镜训练待校准项
- 养成规划：保存单艺人的目标属性、资金、压力与规划策略
- 响应式布局：支持桌面和手机浏览

## 数据说明

当前版本为 `2026.08-M0`。活动名称、方向和部分工资数据已录入；尚未完成重复实测的属性数值不会进入自动规划，以避免输出未经校验的攻略结论。

## 本地运行

这是一个无构建步骤的静态站点。可直接打开 `index.html`，也可以在目录中启动任意静态文件服务器。

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 目录

```text
assets/      图片与本地第三方资源
app.js       页面交互与规划逻辑
data.js      攻略资料数据
index.html   页面结构
styles.css   页面样式
```
